服务端说明 KidsSafeServer

一个跑在你家电脑上的小程序：给家长一个网页后台，给孩子设备一个「配置下发」通道。不需要云服务器、不需要公网、不接任何第三方推送。

接口版本 – 默认端口 5180 .NET 10 Minimal API 运行状态读取中…
它做什么 快速开始 配置项 接口清单 与客户端对接 发版流程 安全须知 常见问题

🧩 它做什么

儿童安全桌面本身是纯离线的，所有设置保存在孩子设备本地。服务端只解决两件「跨设备」的事：

  • 家长后台：在电脑或手机上打开网页，改每日时长、开关小游戏、管理允许的应用，不用拿起孩子的设备。
  • 实时下发：孩子设备会挂一个长轮询请求。家长点保存，设备在 1 秒左右收到变更并应用，看起来像「推送」，但完全不依赖厂商推送通道。
它不做这些：不收集儿童个人信息、不上传使用记录、不代理广告、不需要注册账号。 孩子设备只在家长明确填写服务器地址并开启远程管理后才会连它。

🚀 快速开始

方式一：直接运行（开发 / 试用）

cd KidsSafeServer
dotnet run

看到 Now listening on: http://0.0.0.0:5180 就成功了。

方式二：发布成可执行文件（日常使用）

dotnet publish KidsSafeServer.csproj -c Release -o .\publish
.\publish\KidsSafeServer.exe

打开页面

  • 本机：http://localhost:5180（家长后台）
  • 同局域网其他设备：http://电脑的局域网IP:5180
  • 下载页：/download.html　·　本说明页：/docs.html
  • 首次打开会引导注册家长账号（账号 + 密码）；老版本家长密码 1234 仍可兜底登录，注册账号后自动关闭
  • 儿童端不输家长密码：家长后台「账号与设备」生成 6 位配对码，儿童端填配对码即可同步（只读）
Windows 首次运行时如果弹出防火墙提示，请选择允许专用网络访问，否则手机连不上。

⚙️ 配置项

全部在 appsettings.json，改完重启生效。

配置键说明
AdminPin老版本的单一家长密码，默认 1234。只在「还没注册任何账号」或显式允许时生效，建议注册账号后关掉。
Auth:AllowRegister是否允许继续注册新账号，默认 true。第一个账号永远允许注册；不想让同网段别人注册就改成 false。
Auth:AllowPinLogintrue / false / null。默认 null = 智能：一个账号都没有时允许老密码，注册后自动关闭。
Auth:Secret令牌签名密钥（任意长字符串）。留空则自动生成 data/auth.key；换服务器时把它一起带走，已登录设备才不会掉线。
Site:DownloadUrl外部下载地址（应用市场或对象存储）。留空时下载页使用 wwwroot/downloads/ 里的安装包。
Site:ReleasePage更新日志页地址，默认 changelog.html，随 /api/app/update-check 一起下发给客户端。
Mxnzp:AppId
Mxnzp:AppSecret		故事大全接口的密钥，只保存在服务端，客户端不接触。留空则故事功能不可用。
端口写在 Program.cs 末尾的 app.Urls.Add("http://0.0.0.0:5180")，改端口改这一行。

端口存疑？

监听 0.0.0.0 表示允许局域网访问。只想本机用，把那一行改成 http://127.0.0.1:5180。

📁 目录结构

KidsSafeServer/
├─ Program.cs          接口与路由（所有 endpoint 都在这里）
├─ Releases.cs         版本清单：App 版本与服务端版本的唯一数据源
├─ Downloads.cs        扫描 wwwroot/downloads，生成下载列表与 SHA-256
├─ WatchSignal.cs      配置变更信号（长轮询的版本号，按账号分桶）
├─ MxnzpStoryService.cs 故事代理（密钥仅服务端保存）
├─ Auth/
│  ├─ Accounts.cs      家长账号模型与 accounts.json 存储
│  ├─ AuthService.cs   注册 / 登录 / 配对码 / 令牌解析
│  ├─ PasswordHasher.cs PBKDF2-SHA256 口令哈希
│  └─ TokenService.cs  HMAC 自签令牌
├─ wwwroot/
│  ├─ login.html       登录 / 注册页
│  ├─ index.html       家长后台
│  ├─ download.html    下载安装页
│  ├─ docs.html        本页
│  └─ downloads/       放 apk / zip，页面自动列出
└─ data/
   ├─ accounts.json    家长账号（哈希后的密码，不含明文）
   ├─ profiles/*.json  每个账号一份儿童桌面配置
   ├─ profile.json     老版本单账号配置（未注册账号时使用）
   └─ auth.key         自动生成的令牌签名密钥

换电脑时把整个 data/ 目录拷过去，账号、配置和登录状态就都搬过去了。

🔌 接口清单

除登录与健康检查外，其余接口都需要带 token 查询参数（登录后下发）。返回都是 JSON。

鉴权

接口说明
GET /api/auth/status不需要令牌。返回是否已有账号、能否注册、老密码通道是否还开着，登录页据此决定显示什么。
POST /api/auth/register请求体 {"username":"mama","password":"……","displayName":"小明家"}。第一个账号是管理员，并自动接管原有配置。
POST /api/auth/login 三种请求体：
① {"username":"mama","password":"……"} 家长账号（可写）；
② {"pin":"123456","device":"小明的平板"} 6 位配对码，返回设备令牌（只读）；
③ {"pin":"1234"} 老家长密码（未注册账号时）。
成功 {"ok":true,"token":"…","user":{…}}，失败 401，连续失败 5 次锁 60 秒（429）。
GET /api/auth/me?token=校验令牌并返回当前身份（含 canWrite，设备令牌为 false）。
POST /api/auth/password?token={"oldPassword":"…","newPassword":"…"}。改完旧令牌全部失效。
GET /api/auth/paircode?token=生成 6 位配对码，10 分钟内有效，用一次即作废。
GET /api/auth/devices?token=
DELETE /api/auth/devices/{id}?token=		查看 / 移除已配对设备。移除后该设备令牌立刻失效。

配置与实时通道

接口说明
GET /api/settings?token=读取当前家长配置。
PUT /api/settings?token=保存配置；成功后唤醒所有正在长轮询的设备。POST 同样可用。
GET /api/watch?token=&since=长轮询。版本号与 since 不同立即返回 changed:true，相同时最多挂起 25 秒。

版本与下载

接口说明
GET /api/health健康检查：ok、服务端版本、运行时长、长轮询版本号、保存次数、最新 App 版本。
GET /api/app/release?limit=全部发布记录（不含要点），limit 可只取最近几条。
GET /api/app/release/latest最新一版 + 下载地址 + 更新日志地址。
GET /api/app/changelog?limit=更新日志，含每版要点。
GET /api/app/update-check?versionCode=客户端检查更新；signatureChanged 为 true 表示必须先卸载再装。
GET /api/app/release/{version}指定版本详情，v1.14 与 1.14 都可。
GET /api/download/list扫描 wwwroot/downloads，返回文件名、大小、平台、SHA-256。

受控内容

接口说明
GET /api/content/audio
/video /articles		人工审核过的内置内容目录，不引用第三方。
GET /api/story/types
/list?typeId= /detail?storyId= /search?keyword=		故事代理，统一缓存限流；服务端需能访问外网。

📱 与客户端对接

  1. 在服务端电脑上查到局域网 IP：Windows 执行 ipconfig，找「IPv4 地址」，例如 192.168.1.20。
  2. 孩子设备打开「家长」入口（默认密码 1234，可在应用内修改）。
  3. 在家长面板里填服务器地址 http://192.168.1.20:5180，输入家长密码，开启远程管理。
  4. 回到后台网页改设置并保存，孩子设备会立刻刷新配置。
设备端会在「诊断」页显示长轮询是否在线、最近一次收到变更的时间，连不上时先去那里看。

🏷️ 发版流程

  1. 改 KidsSafeDesktop.csproj 的 ApplicationDisplayVersion（如 1.18）与 ApplicationVersion（如 19，必须递增）。
  2. 在 Releases.cs 的 All 数组最前面插入一条新记录（版本、versionCode、日期、主题、标签、要点）。
  3. 官网 Website/changelog.html 顶部加同样一条，三处版本号保持一致。
  4. 出包后把 apk / zip 放进 wwwroot/downloads/，下载页会自动出现。
  5. 重启服务，/api/health 与 /api/app/release/latest 立刻反映新版本。

为什么要三处同步：客户端读 csproj、服务端读 Releases.cs、官网是静态页，三者没有构建期关联，只能靠流程约束。

🛡️ 安全须知

这个服务端只适合家庭局域网使用。密码已经加盐哈希、令牌是 HMAC 自签并会过期， 但没有 HTTPS、也没有强制改密，任何拿到地址的人仍然可以来试密码（有 5 次失败锁 60 秒的限流）。
  • 不要做端口映射 / 内网穿透把它暴露到公网。
  • 确实需要公网访问时：在自己电脑上直接运行并且前面挂一层带 HTTPS 的反向代理（Nginx / Caddy）。
  • 注册家长账号时用足够长的密码（至少 8 位、别用生日和 123456），并定期更换。
  • 给孩子的设备用配对码，不要直接把家长账号密码告诉孩子 —— 配对码只能拉配置、不能改。
  • 服务只读写 data/ 与 wwwroot/downloads，不要用管理员账号运行。
  • 故事代理的密钥只存在服务端；不要把 appsettings.json 提交到公开仓库。

❓ 常见问题

手机打不开后台页面

  • 确认手机和电脑连的是同一个 WiFi（不是访客网络）。
  • 用电脑浏览器访问 http://localhost:5180/api/health，能返回 ok 才说明服务活着。
  • Windows 防火墙放行 5180 端口，或首次弹窗时选「允许专用网络」。
  • IP 写错很常见：确认是 IPv4 地址，不是 169.254.x.x 这类自动地址。

保存了设置，孩子设备没反应

  • 设备端家长面板里要填服务器地址并开启远程管理，否则它不会连。
  • 设备端「诊断」页看长轮询状态；离线时会在下次联网后自动重连。
  • 服务刚重启时，客户端第一次心跳可能失败一次，几秒后自动恢复。

故事列表加载失败

  • 故事代理需要服务端能访问外网，且 Mxnzp 的 AppId / AppSecret 正确。
  • 家长设置里要开启「在线内容」，否则客户端只用离线内置内容。

数据存在哪里

data/accounts.json 存家长账号（密码是加盐哈希，不是明文）， data/profiles/{账号}.json 存每个账号的儿童桌面配置， data/auth.key 是令牌签名密钥。整个 data/ 目录直接复制就能备份/迁移。

忘记家长账号密码了

  • 本机打开 data/accounts.json，删掉对应账号（或在服务停止时删掉整个文件），等于重新开始 —— 配置会一起丢，先备份 data/。
  • 临时想用老密码：把 Auth:AllowPinLogin 改成 true 重启，用 AdminPin 进来，再重新设置密码。

下载页显示「暂无安装包」

把 apk 或 zip 放进 wwwroot/downloads/ 后刷新页面；或者在 Site:DownloadUrl 配一个外部地址。

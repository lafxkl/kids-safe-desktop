应用权限说明

适用版本 v1.20（versionCode 21）　·　最后更新 2026-11-05　·　本页只讲「安卓端申请了什么」，数据怎么处理请看 隐私政策
一句话结论：安卓端一共申请 7 项权限，全部是「让这个桌面能当桌面用」所必需的， 其中 没有一项能读取你的照片、短信、通讯录、位置或通话记录。 另有 12 类敏感权限我们刻意不申请，包括麦克风、存储读写、无障碍服务和设备管理器—— 这几项恰恰是同类「儿童锁」应用最常用来加强控制的，我们不用。

这份清单可以直接对照手机里的「设置 → 应用 → 儿童安全桌面 → 权限」核对。清单来自安装包内的 AndroidManifest.xml，不是事后补写的说明。

01　申请了哪 7 项

权限（系统里显示的名字）用来做什么拒绝后会怎样
网络访问
INTERNET		 连接你自己填写的家长端服务器；向荣耀推送服务申请消息 token 远程管理不可用，桌面本身照常运行
查看网络连接
ACCESS_NETWORK_STATE		 判断当前有没有网，离线时不去反复连服务器 无感知差异
查看已安装应用
QUERY_ALL_PACKAGES		 在家长面板里列出「孩子可以打开哪些应用」的勾选清单 无法逐个放行，只能整机放行或整机限制

另外清单里还有一条 <queries> 声明，它不是权限，只是 Android 11+ 的「包可见性」规则要求：如果不声明，应用连荣耀推送自己的消息服务都找不到，会出现「能拿到 token、收不到消息」。它只用来查找荣耀推送的组件，不涉及其它应用。

02　容易被误会的两项，单独说明

「查看已安装应用」不是偷看你在用什么

家长面板里要让孩子只能打开指定的几个应用，就必须知道设备上装了哪些应用。这个列表只在本机内存里比对，不上传、不同步、不写日志，家长端服务器也收不到这份清单。

如果你不需要「只放行指定应用」，可以在家长面板里不启用黑白名单，这项权限实际就不会被用到。

「显示在其他应用上层」不是弹广告

这是安卓用来做「悬浮窗」的权限，很多应用拿它弹广告。这里只有一种用法：当孩子从底部上滑、想切到别的应用时，把儿童桌面重新显示出来。

它需要家长在系统设置里手动授予，应用不会硬要。不授予只是防退出变弱，其余功能都正常。

03　我们明确不申请的 12 类权限

下面这些权限，一个都没有申请。列出来是为了让家长能确认「克制」到什么程度。

没有申请的权限如果申请了，本来可以用来做什么
麦克风录音
RECORD_AUDIO		录下孩子说的话。很多「陪伴类」应用靠它做语音对话。本应用没有。
存储读写
READ/WRITE_EXTERNAL_STORAGE、MANAGE_EXTERNAL_STORAGE		翻看相册、往手机里写文件。本应用导出的故事图片只放在自己的缓存目录里，走系统分享面板发出去，不碰相册。
相机
CAMERA		拍照、录像、扫一扫。本应用没有。
位置
ACCESS_FINE_LOCATION、ACCESS_COARSE_LOCATION		知道孩子在哪。本应用不申请；天气按网络粗略判断城市，也可以家长手动设置城市。
通讯录 / 通话记录
READ_CONTACTS、READ_CALL_LOG		读取家里人的电话号码。本应用没有。
短信
READ_SMS、RECEIVE_SMS		读短信验证码、拦截短信。本应用没有。
通知
POST_NOTIFICATIONS		在通知栏弹提醒。正因为没申请，所以这个应用不会给你发任何通知。
无障碍服务
BIND_ACCESSIBILITY_SERVICE		这项最关键。它能读到屏幕上显示的一切内容、代替孩子点击。大量「儿童锁」「防沉迷」类应用靠它做强制拦截。本应用不使用。
设备管理器
BIND_DEVICE_ADMIN		让应用「无法被卸载」，需要家长输密码才能删。本应用没有——孩子或家长随时可以在系统里正常卸载。
日历 / 传感器 / 剪贴板读取读取日程、读取剪贴板里复制过的内容。本应用都没有。
后台自启动 / 常驻前台服务常驻后台不被杀掉。本应用靠「忽略电池优化」这个较温和的方式维持守护，不申请前台服务。
在其他应用上绘制内容
SYSTEM_ALERT_WINDOW 之外的悬浮能力		覆盖在别的应用上面画东西（例如遮罩、广告）。本应用只用它做「把桌面叫回来」，不绘制任何覆盖内容。

04　语音输入为什么不申请麦克风

「无限想象」里有一个 🎤 按钮，可以说话输入。它调用的是手机系统自带的语音识别界面，麦克风权限由那个系统应用自己持有、自己向系统申请。

  • 本应用的权限清单里没有 RECORD_AUDIO；
  • 本应用不保存任何音频，识别完只拿到一段文字；
  • 这个功能默认关闭，第一次用需要家长输入家长密码同意。

如果设备没有系统识别器，麦克风按钮会直接不显示，而不是点了没反应。

05　Windows 版没有权限申请这回事

Windows 版是普通的桌面程序（非应用商店打包格式），安装后不会向你要任何系统权限，也不会弹出「是否允许访问」的窗口。它能做的仅限于用户双击运行时的那点权限，不会开机自启、不注册系统服务。

06　家长怎么自己核对

  • 看已授权的权限：设置 → 应用 → 儿童安全桌面 → 权限。上面 7 项之外如果出现别的，说明装到了改过的包，请从官网重新下载。
  • 看有没有偷偷装别的应用：设置 → 应用 → 查看全部应用，按安装时间排序。
  • 看有没有常驻后台：设置 → 电池 → 耗电排行，或开发者选项里的「正在运行的服务」。
  • 看联网情况：设置 → 网络 → 流量使用情况，找到本应用，未开启家长端服务器时它的流量应当接近 0。

07　权限只减不增

我们的约定是：新版本不会悄悄增加权限。真的需要新增时，会在更新日志里单独标出来，写清楚为什么加、能不能拒绝，而不是混在一堆改动里。

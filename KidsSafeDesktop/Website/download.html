📲 安卓安装步骤

  1. 点「下载 APK」，等浏览器下载完成。
  2. 在通知栏点开安装包；若提示「禁止安装」，进入设置允许该来源安装。
  3. 打开应用，先阅读并同意隐私政策，再进入儿童桌面。
  4. 家长点右下角「家长」，设置每日时长、可用应用与家长 PIN。

🖥️ 电脑端说明

  1. 下载后解压到任意目录，不要直接在压缩包里运行。
  2. 双击主程序启动；首次运行如遇 SmartScreen 提示，选「更多信息 → 仍要运行」。
  3. 电脑端与手机端功能一致，数据各自保存在本机，互不影响。
  4. 想让家长在别的设备上远程管理，再往下部署服务端。
关于杀毒软件误报：安装包没有购买代码签名证书，部分国产杀软会把「未知发布者」的新包标成可疑。 本项目全部源码在 Gitee 公开，可以自行比对、自行编译。介意的话建议用免安装版，用完直接删目录。

二、服务端部署（可选）

一个几十 MB 的 ASP.NET Core 程序，跑在家里的电脑、NAS 或小主机上，不建议暴露到公网

装它能多做什么

能力说明
远程改配置每日时长、可用应用白名单、主题、在线内容开关，浏览器里改完自动下发
设备配对后台生成 6 位配对码，孩子端填一次即绑定，家长密码不用告诉孩子
实时下发改完 1 秒内生效，孩子设备不用重启、不用手动同步
多账号隔离一台服务器可以给多个家庭用，各账号的配置与设备互不可见
使用统计看每台设备当天用了多久、打开了哪些应用

🧰 运行要求

  • 一台常年开机的设备：旧笔记本、NAS、树莓派、小主机都行
  • .NET 10 SDK（自行编译）或 .NET 10 运行时（跑发布产物）
  • 与孩子设备在同一个局域网；跨网访问需自己配穿透，见文末警告
  • 磁盘占用：程序本体几十 MB，加上安装包与课本后按实际内容算

🚀 三步跑起来

  1. 取源码 
    # 需要先装 .NET 10 SDK
git clone https://gitee.com/lafxluc/kids-safe-desktop.git
cd kids-safe-desktop/KidsSafeServer
  2. 启动（默认监听 5180 端口，可用 KS_URLS 改） 
    # 直接跑
dotnet run -c Release

# 或者发布成独立目录，之后反复启动更快
dotnet publish -c Release -o out
dotnet out/KidsSafeServer.dll
  3. 注册家长账号：浏览器打开 http://这台电脑的IP:5180， 首次访问会自动跳到注册页。第一个注册的账号是管理员，原有配置会自动迁移过来。
  4. 配对设备：后台「👤 账号与设备」→ 生成 6 位配对码（10 分钟内有效、用一次即废）→ 在孩子端「家长服务器」里填地址和配对码。
配对码和设备令牌都是只读的。孩子设备能拉配置，但改不了配置； 家长改密码只会踢掉其他家长端的登录，不会把孩子平板踢下线。

⚙️ 常用配置

改 appsettings.json 后重启生效；也可以直接用环境变量覆盖。

配置项作用
KS_URLS监听地址与端口，如 http://0.0.0.0:5180
Auth:RegistrationOpen是否允许继续注册新账号；家庭自用可在注册完后关掉
Auth:AllowPinLogin是否接受老密码登录；null 表示有账号后自动关闭
Site:DownloadUrl下载页优先使用的跳转地址，可指向对象存储
Story:*第三方故事接口的密钥，只存在服务端，不下发到客户端

数据都在服务端目录的 data/ 下：accounts.json（账号）、 auth.key（令牌签名密钥）、profiles/{账号ID}.json（每个家庭的配置）。 整个 data 目录拷走就是完整备份。

不要把这个服务端直接暴露到公网。它是给家庭局域网设计的：没有 HTTPS、没有复杂的风控， 令牌密钥就躺在 data/auth.key 里。做端口映射或内网穿透前请想清楚—— 确实需要远程访问时，至少在前面挂一层带 HTTPS 和登录的反向代理（Nginx / Caddy），并限制来源 IP。

# 02 · 构建与运行

## 1. 先把话说清楚：三种「跑起来」

| 目的 | 做法 | 注意事项 |
| --- | --- | --- |
| 改代码看效果 | `./build/kidssafe --windowed` | **窗口模式**，不然全屏 + 抢焦点，退出要切 TTY |
| 验环境 / 排障 | `./build/kidssafe --self-test` | 不开界面、不需要显示器，输出环境清单，退出码 0/1 |
| 给用户用 | `./scripts/install.sh` 或装 `.deb` | 进登录界面，选「儿童安全桌面」 |

`--self-test` 会打印：日志路径、Qt 与 Breeze 样式、语音、kiosk 会话、
故事服务器、在线内容、网页小游戏目录、天气缓存、NES、小小程序员（有没有 gcc）、
故事剧场（有没有吉里吉里）。**排障先跑它**，绝大多数问题在输出里就写着了。

## 2. Linux 版

### 2.1 依赖

```sh
sh scripts/install-deps.sh        # Debian / Ubuntu / deepin，一条命令装齐
```

手工版（Debian 系真实包名，Fedora 的包名不一样，别混着抄）：

```sh
sudo apt install build-essential cmake extra-cmake-modules \
     qt6-base-dev qt6-declarative-dev \
     qt6-webengine-dev qt6-multimedia-dev \
     libkf6config-dev libkf6coreaddons-dev libkf6i18n-dev \
     libkirigami-dev qml6-module-org-kde-kirigami \
     qml6-module-qtquick qml6-module-qtquick-window \
     qml6-module-qtquick-controls qml6-module-qtquick-layouts \
     qml6-module-qtquick-templates qml6-module-qtqml-workerscript \
     qml6-module-org-kde-breeze qml6-module-qtwebengine
```

`qt6-webengine-dev` 与 `qt6-multimedia-dev` 是**必需**的，缺了 cmake 直接失败。
不是因为「少个功能」，而是网页小游戏的初始化代码和 QML 宿主页要在编译期编进
二进制 —— 构建机上没有，用户事后装 `qml6-module-qtwebengine` 也补不回来。
真要一个不含它的极小包，显式 `-DKIDSSAFE_MINIMAL=ON`。

### 2.2 编译

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel "$(nproc)"
./build/kidssafe --windowed
```

或者 `./scripts/install.sh`（编译 + 装到 `/usr/local` + 建会话入口）。

### 2.3 两个会浪费半天的坑

1. **改了 QML 必须重新跑一遍 `cmake`**。QML 是编进 qrc 的，`cmake --build`
   本身不会重新生成资源清单 —— 新加的 `.qml` 不重新 configure 就**不在 qrc 里**，
   表现是运行期白屏、编译期一句话都不报。加文件后要么重跑 `cmake`，
   要么直接 `rm -rf build`。
2. **Breeze 样式模块不在时不要硬设**。`QQuickStyle::setStyle("org.kde.breeze")`
   指向不存在的模块时 Qt 不会退回默认样式，而是让第一个
   `import QtQuick.Controls` 的文件编译失败、整个界面白屏。`main.cpp` 现在会
   先探 `org/kde/breeze/qmldir` 再决定。

### 2.4 deepin 25 专有的四处

1. apt 源必须用 `crimson` 套件；同一 URL 下的 `beige` 也在线，但里面没有 KF6、
   Qt 也是旧的，选错会连环报「无法定位软件包」。
2. Kirigami 的开发包叫 `libkirigami-dev`，**不带 kf6 前缀**（KF6 全家只有它例外）。
   写错的话 apt 整条命令中止，同一条命令里其它包也不会装。
3. 没有 `qqc2-breeze-style`（那是 Fedora/Arch 的名字），Ubuntu 是
   `qml6-module-org-kde-breeze`，deepin 干脆没有。
4. KF6 可能缺 `KF6Config.cmake` 总入口，`CMakeLists.txt` 已做逐个
   `find_package(KF6Xxx)` 的兜底。

`libxkbcommon-dev` 不是本工程依赖（代码里一行都没用），只在 cmake 报 XKB 错时
临时装；写进 `debian/control` 会让 deepin 上的 `dpkg-checkbuilddeps` 直接拒绝打包。

## 3. Windows / Android

```sh
# Windows
dotnet build KidsSafeDesktop.csproj -f net10.0-windows10.0.19041.0
dotnet run   --project KidsSafeDesktop.csproj -f net10.0-windows10.0.19041.0

# Android（需 Android SDK + maui-android workload）
dotnet build KidsSafeDesktop.csproj -f net10.0-android
```

**必须带 `-f`**：工程是多目标的，不指定会连 Android 一起还原。

需要自己准备、但不在仓库里的文件（缺了功能降级，`dotnet build` 仍能过）：

```sh
cp Signing.props.sample Signing.props                              # Android 打包必需
cp Scripts/deploy.config.sample.json Scripts/deploy.config.json     # 只在部署官网时需要
# Keys/kidssafe.keystore                                            # 自己的签名证书
# Platforms/Android/Assets/mcs-services.json                        # 荣耀推送
```

iOS：`net10.0-ios`，最低 iOS 15，只有内容版。见 `Docs/iOS上架说明.md`。

## 5. 运行期的环境变量

| 变量 | 作用 |
| --- | --- |
| `KIDSSAFE_BIN` | 会话脚本用哪个二进制（默认按 `/usr/local/bin`、`/usr/bin` 找） |
| `KIDSSAFE_KIOSK_SESSION=1` | 标记「这是 kiosk 会话」，会话脚本会设 |
| `KIDSSAFE_WEB_GPU=1` | 放开 WebEngine 的 `--disable-gpu`（默认软件合成） |
| `KIDSSAFE_PLAYLAND_DIR` / `KIDSSAFE_MAKER_DIR` / `KIDSSAFE_CODELAB_DIR` | 覆盖网页游戏 / 工坊 / 关卡表目录，改素材不用重装 |
| `QTWEBENGINE_CHROMIUM_FLAGS` | 直接改 Chromium 参数（程序会往里追加，不覆盖） |

自带运行时那套包另外用 5 个 `QTWEBENGINE_*` 变量定位资源，见
[05 打包与分发](05-打包与分发.md)。

# 04 · 功能地图

按孩子从打开到关掉的顺序排。每节末尾标了实现位置（Linux 版）与细节文档。

## 1. 开机 → 首页

```
SplashPage（2.6 秒动画，期间并行初始化：设置 → 护眼 → 账号 → 时长 → 儿童模式）
      ↓
OnboardingPage（仅首次：家长 PIN → 选主题 → 选允许的应用）
      ↓
HomePage（桌面：天气条 + 应用磁贴 + 底部入口）
```

首页磁贴：故事屋、安全世界、游戏乐园、儿童桌面、小小程序员、项目工坊、
媒体中心、红白机、故事剧场、护眼操。点磁贴进页面，全部走 `StackView`。

右上角头像进「家长中心」：先过 PIN 门（`ParentGatePage`），再进
`ParentDashboardPage`（时长、白名单、联网开关、退出）。

## 2. 故事屋

- 本地：`Linux/server/data/stories.json`（示例 19 篇）+ `stories/` 目录下丢 txt 即用。
- 在线：家长的服务器地址可配；`onlineContentEnabled` 关闭时只读本地。
- 播放：`StoryReaderPage` 逐句高亮 + `Speech`（`spd-say`）朗读；没有 TTS 就静音降级。

## 3. 安全世界

10 个主题、52 条安全贴士、40 道问答，数据与三端同源
（`SafetyData.js` / `SafetyQuiz.js`）。流程：主题列表 → 知识点 → 小测。

## 4. 游戏乐园

| 类型 | 有哪些 | 说明 |
| --- | --- | --- |
| 原生小游戏 | 数一数、拼图配对、找颜色、算术乐园、打地鼠 | 纯 QML，无外部依赖 |
| 华容道 | 三套布局（6/8/9 棋子） | A\* 验过最优解 14 / 27 / 51 步；支持方向键、退一步、联机竞速 |
| 国际象棋 | 人机三档 + 联机对战 | 纯 JS 引擎，perft 校验；AI 深度 1/2/3 + 随机 slack |
| 网页小游戏 | 15 款 HTML5 | QtWebEngine 内嵌，与 Windows/Android 共用同一份 `assets/playland` |

难度三档只影响出题范围和 AI 强度，不影响能不能玩 —— 孩子选错难度不该被卡住。

## 5. 儿童桌面（Linux 独有）

| 工具 | 能力 | 限制 |
| --- | --- | --- |
| 文件管理器 | 浏览、预览、复制/删除（进自己的回收站）、重命名 | 系统目录只读；只能在自己的目录里操作 |
| 终端 | 真 PTY，常用命令快捷按钮，清屏，危险命令拦截 | 只做着色，`vim`/`htop` 会花屏 |
| 任务管理器 | 进程列表、CPU 占用、结束进程（两步确认） | 只能结束自己权限内的进程 |

三个工具都画在同一个页面里，**不开真顶层窗口** —— kiosk 会话没有窗口管理器，
开真窗口会得到一堆没有边框、关不掉、叠在一起的东西。

## 6. 小小程序员

32 关，从「让小猫走一步」到「循环 + 条件」。积木拼出来的逻辑生成 C 源码，
调系统 `gcc` 编译后运行，用 stdout 判题。没有 gcc 时页面照常打开，只是不能运行
（自检里会写「小小程序员：未找到 gcc」）。

关卡表：`assets/codelab/lessons.json`。

## 7. 项目工坊

拆三个现成作品：飞机大战（PlaneWar）、推箱子（Sokoban）、平台跳跃（Platformer）。
左边项目列表，中间游戏 + 代码，右边「怎么玩 / 在教什么 / 改一改」（滑块调参数）。

这是个「读别人的代码」的入口，不是编辑器 —— 编辑器在「小游戏工坊」。

## 8. 小游戏工坊 / 媒体中心 / 红白机 / 故事剧场

| 模块 | 是什么 | 缺依赖时 |
| --- | --- | --- |
| 小游戏工坊 | 内置网页编辑器，画一画就能做出小游戏，作品存成本地文件 | 没有 WebEngine 时入口不可用 |
| 媒体中心 | 8 首儿歌 + 3 段环境音 + 国学朗读 | 没有 QtMultimedia 时只能看不能播 |
| 红白机 | SimpleNes 核心，ROM 自管、存档、快照 | 无声音时静音运行 |
| 故事剧场 | 吉里吉里（KiriKiri 2）游戏，起外部引擎 | 没装运行时则入口提示 |

## 9. 家长中心

| 能力 | 说明 |
| --- | --- |
| 每日时长 | 到点锁屏（`LockoutPage`），家长 PIN 可临时加时 |
| 应用白名单 | 只显示勾选过的应用；引导页第 4 步就是第一次配置 |
| 联网开关 | `onlineContentEnabled`（故事/天气）与 `netplayEnabled`（联机）分开，默认都关 |
| 护眼 | 20 分钟提醒远眺 + 护眼操页面 |
| 反馈 | 提交到服务器，官网有公开统计（`Docs/用户反馈与问卷.md`） |
| 退出 | 写 `.session_exit` 标记，守护循环才真的退出会话 |

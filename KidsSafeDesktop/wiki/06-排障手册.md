# 06 · 排障手册

## 1. 先做这三件事

```sh
./build/kidssafe --self-test          # 环境清单 + 退出码（0 通过 / 1 有问题）
tail -40 ~/.local/share/kidssafe/kidssafe.log
```

日志里每行都带 `[模块]` 前缀（`[app]` `[nav]` `[playland]` `[lab]` `[weather]`…），
先看最后 10 行是哪一类，再往下查。

**分清「编译期」和「运行期」**：QML 是编进 qrc 的，但语法错误只在运行时才报。
所以「编译通过了」不代表界面对 —— 看日志里有没有 `页面编译失败`。

## 2. 日志关键字对照表

| 日志 | 真正的原因 | 怎么改 |
| --- | --- | --- |
| `[nav] 页面编译失败 … X.qml:12 Invalid property assignment: int expected` | 给 int 属性写了小数（`font.pixelSize: 13.5`） | 取整。这一行会让**整个页面**进不了页面栈，连带引用它的页面一起打不开 |
| `Property names cannot begin with an upper case letter` | 属性名叫 `W` / `H` | 改小写，引用点一起改 |
| `Expected token ','`（在 `property var x: { … }` 处） | 对象字面量少了括号，QML 把 `{` 当成一组属性赋值 | 写成 `({ … })` |
| `ReferenceError: index is not defined` | `ListView` 委托里用了 `required property`，上下文属性注入被关掉，`index` 不可见 | 委托里显式 `required property int index` |
| `Unable to assign TextArea_QMLTYPE_x to QQuickTextInput` | Breeze 样式的 `TextArea` 在 Qt 6 上的 bug | 只读文本改用自绘的 `CodeView.qml` |
| `module "org.kde.breeze" is not installed` | 系统没装 Breeze 样式模块 | 装 `qml6-module-org-kde-breeze`；`main.cpp` 已做探测兜底 |
| `no Qt platform plugin could be initialized` | 缺 `platforms/libqxcb.so` 或 `QT_PLUGIN_PATH` 指错 | 自带包：`kidssafe.sh` 里那行 `QT_PLUGIN_PATH` 有没有生效 |
| `Could not find QtWebEngineProcess` | 自带包漏了 helper 进程 / 环境变量没设 | 看 `[webengine]` 那行日志里哪个 ✗ |
| `[playland] 本次构建未包含 QtWebEngine` | 编译时没有 `qt6-webengine-dev` | 装包重编；或直接用自带包 |
| `[lab] 项目加载失败：projects/X.qml` | 那个项目文件本身没通过编译 | 往上翻一行，真正的语法错误在它前面 |
| `[weather] 天气请求失败：超时（8 秒没有响应）` | 网络到不了 Open-Meteo，或系统时间不对 | 断网时是预期行为（有缓存），不影响其它功能 |
| `Failed to register with host portal … Connection already associated` | XDG 桌面的常规警告，Qt 6 在缺 portal 的环境里打一条 | 忽略 |
| `Unable to assign … to QQuickTextInput`（重复刷） | 同上 Breeze bug | 同上 |
| `qt.qpa.xcb: could not connect to display` | 在纯 SSH / 无 X 的会话里跑 GUI | 用 `--self-test`，或 `QT_QPA_PLATFORM=offscreen` |
| 终端里中文变成一堆小方块（`下载 ▯▯▯`） | UTF-8 解码按「攒够 4 字节就解一次」切，3 字节的汉字被从中间切断，解出替换符后又用 `fromLocal8Bit` 转了一道，把好字也毁了 | 按首字节决定这个字共几字节再解（`terminal.cpp` 的 `pushUtf8`），修好后 1/2/3/4/7 字节任意切分都不出错 |
| 终端里出现 `[01;34m` 这类字样 | ANSI 转义没被识别（改了 `handleAscii` 状态机就会这样） | 检查 `m_state` 的 `Escape→Csi→Normal` 三条转移是否完整 |

## 3. 界面「布局错乱」的四个常见根因

这四条在项目里都真实踩过，症状看着都是「位置不对」，原因完全不同：

**① 给 `RowLayout` / `ColumnLayout` 的直接子项写 `width` / `height`。**
布局赋值会把绑定顶掉，子项宽度变 0。如果这个子项内部用绝对坐标画（棋盘
Grid、Canvas），它会从 0 宽的父项里照常往外画 —— 看起来只是「右边面板压在
棋盘上」。改法：用 `Layout.preferredWidth/Height`，或者干脆不用布局，自己算
`x/y/width/height`。

**② 嵌套布局里指望 `Layout.fillWidth` 一路传下去。**
外层的 `fillWidth` 不会让内层容器自动撑开，内层会停在自己的
`implicitWidth`（往往是最长那行文字/输入框的宽度），于是内容全挤在左边。
改法：尺寸由页面统一算出（`cardWidth` / `innerWidth`），每层显式赋值。

**③ 窗口里的内容用固定像素，缩放 125% / 150% 时错位。**
本项目统一用 `Kirigami.Units` 或按 `font.pixelSize` 的比例算，不写死像素。

**④ 网页那部分（`assets/maker`、`assets/playland`）：`hidden` 属性没真的隐藏。**
浏览器默认样式里 `[hidden]{display:none}` 属于**用户代理样式表**，作者样式表里
任何一条 `display:flex` 都能盖掉它（跟选择器优先级无关，只跟来源有关）。
`<div class="sheet" hidden>` 只要 `.sheet{display:flex}` 在，就照样铺满全屏。
小游戏工坊就是这样坏的：素材选择器的半透明遮罩永远压在最上层，整页点不动，
大厅和编辑台还同时显示。改法是在样式最前面写一条
`[hidden]{display:none !important}`，一次性管住所有类似元素。

## 4. 内容「是空的」

| 现象 | 原因 |
| --- | --- |
| 网页游戏卡片全空 | 没有 WebEngine，或资源目录里找不到 `index.html`（`[playland]` 那行会打印实际目录） |
| 项目工坊右侧「怎么玩 / 在教什么」空 | 对应的 `projects/*.qml` 没编译过（上面的属性名大小写、括号问题） |
| 「看代码 / 运行结果」是个灰框 | Breeze `TextArea` bug，见上表 |
| 桌面一个应用都没有 | 引导页勾选没写进配置（`index is not defined`），或白名单为空 |
| 故事屋空白 | `serverUrl` 没配 + 本地 `stories.json` 被移走 |

## 5. 打包相关

| 报错 | 原因 |
| --- | --- |
| `Unmet build dependencies: …` | 见 `Linux/README.md` 第七节：真的要用就装，只是某发行版顺带要的就从 `debian/control` 删掉 |
| `debian/kidssafe.docs: README.md: not found` | `debian/*.docs` 带了执行位，debhelper 把它当脚本跑。`chmod -x debian/kidssafe.docs` |
| 装包时 `无法被用户 '_apt' 访问，已脱离沙盒并提权为根用户` | 通知不是错误：家目录 750，`_apt` 进不去。把包放 `/tmp` 再装即可 |
| 自带包跑起来白屏、`[webengine]` 全是 ✗ | `kidssafe.sh` 没被用上（直接跑了 `bin/kidssafe`）—— 必须从启动器进 |
| 自带包启动报缺 `libxxx.so` | 该库在依赖遍历时被跳过了（`skip_lib` 的黑名单），或属于显卡驱动 |

## 6. 改完没生效？

- **改了 QML 必须重新跑 `cmake`**（qrc 清单不会自己更新），最省事是
  `rm -rf build && cmake -S . -B build && cmake --build build`。
- 改了 C++ 只需 `cmake --build`。
- 界面还是旧的：确认跑的是新构建出来的那个二进制（`which kidssafe` 可能是
  `/usr/local/bin` 里的旧安装）。

## 7. 收集信息

用户报问题时让他给三样东西，基本一次就能定位：

1. `./kidssafe --self-test` 的完整输出；
2. `~/.local/share/kidssafe/kidssafe.log` 的最后 40 行；
3. 发行版与版本（`cat /etc/os-release | head -3`）、Qt 版本（`qmake6 -query QT_VERSION`）、
   装的是薄包还是自带包。

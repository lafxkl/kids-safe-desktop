# 09 · 依赖清单（给用户看）

这一页回答一个问题：**我要在自己机器上跑起来，到底要装什么。**

先分三种人，别混着看：

| 你是谁 | 要做的事 | 跳到 |
| --- | --- | --- |
| 我只是想装上给孩子用 | 装一个 `.deb`，**一个依赖都不用自己装** | [第 1 节](#1-只想用装-deb-就行不用读这份文档) |
| 我要自己编译 | 按第 2、3 节装一遍（一条命令） | [第 2 节](#2-自己编译要装什么) |
| 我打好的包装到别的机器上跑不起来 | 看第 6 节的「自带包」和系统要求 | [第 5 节](#5-三种安装方式的依赖差别) |

---

## 1. 只想用：装 deb 就行，不用读这份文档

```sh
sudo apt install ./kidssafe_1.19.0_amd64.deb
```

运行期要的东西都写在包里的 `Depends` 里，apt 会一起装上。装完注销、在登录界面
右下角选「儿童安全桌面」，重新登录即可。

只有两种情况需要往下读：

- 你**不用 apt 装**（自己编、解压绿色包、拷到没有网络的机器上）；
- 你的机器不是 Debian / Ubuntu / deepin（包名全都不一样）。

---

## 2. 自己编译要装什么

一条命令（Debian / Ubuntu / deepin，脚本会自己跳过源里没有的包）：

```sh
sudo ./scripts/install-deps.sh
```

装完它会自己校验一遍。手工装的话，就是下面这些包：

```sh
sudo apt install build-essential cmake extra-cmake-modules \
     qt6-base-dev qt6-declarative-dev qt6-webengine-dev qt6-multimedia-dev \
     libkf6config-dev libkf6coreaddons-dev libkf6i18n-dev libkirigami-dev \
     libx11-dev \
     qml6-module-qtquick qml6-module-qtquick-window \
     qml6-module-qtquick-controls qml6-module-qtquick-layouts \
     qml6-module-qtquick-templates qml6-module-qtqml-workerscript \
     qml6-module-org-kde-kirigami qml6-module-qtwebengine
```

### 2.1 每个包是干什么的，缺了会看到什么

**编译期必需**——少一个 `cmake` 就过不去：

| 包 | 干什么 | 缺了会怎样 |
| --- | --- | --- |
| `build-essential` | g++ 编译器（要 C++20，GCC 11 起） | cmake 报 `CXX_STANDARD 20` 不支持 / 找不到编译器 |
| `cmake` ≥ 3.20 | 构建系统 | 无法 configure |
| `extra-cmake-modules` | 提供 KF6 的 CMake 入口 `KF6Config.cmake` | 报找不到 KF6 组件（脚本会退回逐个查找，能过但会多几行日志） |
| `qt6-base-dev` | Qt6 的 Core / Gui / Widgets / Network | 第一个 `find_package(Qt6)` 就失败 |
| `qt6-declarative-dev` | QtQuick 与 QtQuick.Controls | 同上 |
| `qt6-webengine-dev` | **网页小游戏（15 款 HTML5）** 的内嵌引擎 | cmake 直接报「缺少 QtWebEngine」，并打印该装的包名 |
| `qt6-multimedia-dev` | 红白机声音、媒体中心（听一听） | cmake 直接报「缺少 QtMultimedia」 |
| `libkf6config-dev` | 读写配置（`~/.config/kidssafe/kidssafe.conf`） | 找不到 `KF6Config` |
| `libkf6coreaddons-dev` | KF6 基础工具类 | 同上 |
| `libkf6i18n-dev` | 多语言（`i18n()`） | 同上 |
| `libkirigami-dev` | QML 组件与主题 | 找不到 `KF6Kirigami`，整个界面起不来 |
| `libx11-dev` | X11 下抢走 Alt+Tab / Ctrl+Shift+Esc | **能编过**，但打包出来的程序会静默失去「屏蔽快捷键」这一项 |

> ⚠️ 最后两个（`qt6-webengine-dev` / `qt6-multimedia-dev`）不是「有就带上」的可选功能。
> 缺了它们编出来的程序里**没有那段初始化代码**，事后再装 QML 模块也补不回来，
> 只能重新编译。所以默认直接报错停下，而不是给你一个残废的包。

**运行期必需**——编好了、但菜单里点开是白屏，通常是这里缺东西：

| 包 | 什么时候需要 | 缺了会怎样 |
| --- | --- | --- |
| `qml6-module-qtquick`<br>`-window` `-controls` `-layouts` `-templates`<br>`qml6-module-qtqml-workerscript` | 每个页面都用 | 窗口能起来、**界面是空的**，日志里是 `module "QtQuick.Controls" is not installed` |
| `qml6-module-org-kde-kirigami` | 页面框架 | 启动即报 `module "org.kde.kirigami" is not installed`，窗口一片空白或直接退出 |
| `qml6-module-qtwebengine` | 网页小游戏 | 打开「网页游戏乐园」报 `module "QtWebEngine" is not installed` |

用 `.deb` 装的话，这三行已经在 `Depends` 里；只有「从 build 目录直接跑」或
「拷绿色包」时才需要自己确认。

### 2.2 其它发行版的包名

同一批东西，三个发行版三个叫法，照着抄最不容易错：

| 用途 | Debian / Ubuntu / deepin | Fedora | Arch |
| --- | --- | --- | --- |
| 编译器 + cmake | `build-essential cmake extra-cmake-modules` | `cmake gcc-c++ extra-cmake-modules` | `base-devel cmake extra-cmake-modules` |
| Qt 基础 | `qt6-base-dev qt6-declarative-dev` | `qt6-qtbase-devel qt6-qtdeclarative-devel` | `qt6-base qt6-declarative` |
| 网页引擎 | `qt6-webengine-dev` | `qt6-qtwebengine-devel` | `qt6-webengine` |
| 音频 | `qt6-multimedia-dev` | `qt6-qtmultimedia-devel` | `qt6-multimedia` |
| KF6 配置 / 核心 / i18n | `libkf6config-dev libkf6coreaddons-dev libkf6i18n-dev` | `kf6-kconfig-devel kf6-kcoreaddons-devel kf6-ki18n-devel` | `kconfig kcoreaddons ki18n` |
| Kirigami | `libkirigami-dev`（老源里叫 `libkf6kirigami-dev`） | `kf6-kirigami-devel` | `kirigami` |
| Breeze 样式 | `qml6-module-org-kde-breeze` | `qqc2-breeze-style` | `breeze` |

QML 运行时模块在 Fedora / Arch 上是跟着 `qt6-qtdeclarative` / `qt6-declarative`
和 `qt6-qtwebengine` / `qt6-webengine` 一起装的，不用单独找包名。

## 3. 可选依赖：不装也能用，只是少一块

| 包 | 给哪个功能 | 不装的话 |
| --- | --- | --- |
| `speech-dispatcher` | 国学启蒙的朗读（依赖里面的 `spd-say`） | 点朗读提示「未安装 speech-dispatcher」，其它照常 |
| `gcc` | 小小程序员 · 32 关（要真的编译并运行孩子写的 C） | 能看代码、能翻关卡，点「运行」时提示需要家长装编译器 |
| `qml6-module-qtquick-dialogs` | 小游戏工坊的「导入素材 / 打开作品」 | 提示「文件选择器不可用」，编辑器照常画、照常试玩 |
| `qml6-module-org-kde-breeze` | 控件观感与 KDE 桌面一致 | 回退到内置样式，功能一点不少，只是长得不太一样 |
| `qt6-multimedia-ffmpeg` 或 `qt6-multimedia-gstreamer` | 真正解码音频/视频的插件 | **能编译、点了没声音、也没有任何报错**——这个最难查，见第 7 节 |
| `kwin-wayland` 或 `cage` | Wayland 会话的合成器 | X11 会话不受影响；Wayland 会话会直接退出并提示「需要 kwin_wayland 或 cage 之一」 |

## 4. 装完怎么确认

按顺序跑，哪一步红了就修哪一步：

```sh
sudo ./scripts/install-deps.sh     # 装依赖（末尾自带校验，会逐个 import 试一遍 QML 模块）
./scripts/check-host.sh            # 只读体检：可执行文件、会话文件、合成器、字体、音频……
./build/kidssafe --self-test       # 程序自检，退出码 0 才算过
ldd ./build/kidssafe | grep "not found"    # 应该一行都没有
```

`check-host.sh` 只读、不改系统，适合装在别人机器上先探一遍再决定装什么。

如果只想知道「网页引擎到底在不在」，看程序启动日志里的这一行：

```
[app] 本次构建未包含 QtWebEngine，网页小游戏不可用
```

有这行 = 编译时就没编进去（要重编，装包没用）；没有这行、但打开网页页白屏 =
运行期模块没装（`qml6-module-qtwebengine`）。

## 5. 三种安装方式的依赖差别

| 装法 | 用户机器要装什么 | 体积 | 说明 |
| --- | --- | --- | --- |
| **deb · 薄包**（`scripts/build-deb.sh`） | 系统的 Qt6 / KF6 / WebEngine，由 apt 自动装 | ~3 MB | 走发行版的包，升级 Qt 时跟着一起升，最省事 |
| **deb · 自带包**（`scripts/bundle-runtime.sh --deb`） | **什么都不用装**（Qt、KF6、WebEngine 全在 `/opt/kidssafe`） | ~120 MB | 给「源里没有 Qt6」或「Qt 版本对不上」的机器 |
| **绿色包**（`bundle-runtime.sh --tgz`） | 同上，解压即用 | ~300 MB 解压后 | 不用安装、也写不进登录会话，只适合临时试 |

自带包不是万能的，它只解决「系统没有 Qt」，**不解决「系统太老」**：glibc、
libstdc++、显卡驱动不能随包带走（必须和内核/驱动匹配），所以它仍然要求目标
系统的 glibc 不低于打包机器的。

## 6. 系统要求（实测口径）

| 项 | 要求 | 说明 |
| --- | --- | --- |
| Qt | **6.5 或更新** | `find_package(Qt6 6.5)`；实测环境是 deepin 25 / Qt 6.8 |
| KF6 | 6.0 或更新 | Config / CoreAddons / I18n / Kirigami 四个组件 |
| 编译器 | 支持 C++20（GCC 11+） | 只在编译时需要 |
| glibc | 2.34+ | 终端用了 `forkpty`，它自 2.34 起并进 libc；更老的发行版会缺 `libutil` |
| 桌面会话 | X11 或 Wayland 都行 | Wayland 下需要 `kwin_wayland` 或 `cage`；没有窗口管理器也能跑（界面自绘） |

已实测：deepin 25（Qt 6.8，X11 会话）主链路全通。Ubuntu 24.04 包名一致。
比 Ubuntu 22.04 更老的发行版自带 Qt 6.2，**低于 6.5**，源码编译过不去 ——
要么升 Qt，要么用自带包（且 glibc 得够新）。

## 7. 几个「装了却像没装」的坑

这几条在 [06 排障手册](06-排障手册.md) 里有更细的排查步骤，这里只列结论：

1. **`apt install --no-install-recommends`** 会把 `Recommends` 整片跳过。
   本项目的 `qml6-module-qtquick-dialogs`、`speech-dispatcher`、音频解码插件都在
   `Recommends` 里，这么装出来就是「能开、少功能」。介意的话去掉这个参数。
2. **音频解码插件**（`qt6-multimedia-ffmpeg` / `gstreamer`）缺失时，程序
   **不会报错**，只是点了没声音。判断方法是看一眼包在不在，而不是听。
3. **`qt6-webengine-dev` 和系统的 Qt 版本必须一致**。混着装（比如系统 Qt 6.4、
   dev 包 6.8）能编过，运行时崩在 Chromium 初始化。用发行版仓库里的配套版本。
4. **改过 QML 之后必须重跑 `cmake`**（不是只 `cmake --build`）。新加的 `.qml`
   不在 qrc 里时，编译期不报错、运行期白屏 —— 这一条踩过不止一次。
5. **`libxkbcommon-dev` 不是本项目的依赖**。只有 cmake 报 XKB 相关错误时才临时装，
   写进依赖清单反而会让 `dpkg-checkbuilddeps` 在没这包的机器上拒绝打包。

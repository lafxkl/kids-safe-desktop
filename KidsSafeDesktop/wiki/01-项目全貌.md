# 01 · 项目全貌

## 1. 它到底是什么

一个**登录会话**，不是一个普普通通的应用窗口。孩子开机（或在登录界面选
「儿童安全桌面」）之后，进来的就是这里：没有任务栏、没有文件管理器可乱翻、
没有浏览器入口、按 Alt+Tab 切不出去。到点自动锁屏，家长用 PIN 退出。

同一套产品做了四个端，定位不一样：

| 端 | 定位 | 和别人不一样的地方 |
| --- | --- | --- |
| Windows | 主力形态，家长电脑给孩子用 | 装成当前用户、不弹 UAC；低级键盘钩子拦快捷键 |
| Android | 平板 / 手机 | 默认桌面 + 无障碍拦截设置/商店/卸载 |
| iOS | 内容版，不做受控桌面 | 保留内容侧，不做 kiosk（系统不允许） |
| Linux | KDE Plasma 下的独立会话 | 会话裁剪（不启 plasmashell），Wayland 也成立 |

iOS 为什么只做「内容版」：`Docs/iOS上架说明.md`。

## 2. 三个 MAUI 工程怎么分工

```
KidsSafeShared/      87 个页面 + ViewModel + Service 接口 + Model（代码只有一份）
KidsSafeDesktop/     孩子端外壳：入口、平台实现、图标资源、打包脚本
KidsSafeParent/      家长端外壳：同一套页面的另一个入口
```

拆之前，家长中心只靠一道 PIN 门挡在孩子端里；拆之后，家长端是**独立的 App**，
孩子端的 APK 里根本没有家长那部分界面。

命名空间仍然是 `KidsSafeDesktop.*`（搬家时没改名），所以在孩子端工程里会看到
`using KidsSafeDesktop.Pages;` 这种「引用自己」的写法 —— 它引用的是共享库。

细节：`Docs/工程结构-家长端拆分.md`。

## 3. 代码地图

```
KidsSafeDesktop/
├── App.xaml(.cs)          入口：隐私政策 → Splash → Onboarding → Home
├── MauiProgram.cs         DI 注册：先挂日志，再注册真实服务 + 平台服务
├── Platforms/
│   ├── Android/           MainActivity（儿童模式/沉浸式/返回键）、荣耀推送、aar
│   └── Windows/           WinUI 入口、应用枚举、原生音频、任务栏恢复兜底
├── Resources/             图片、字体、Raw/（内置网页、音频、题库、游戏）
├── Installer/             Inno Setup，装当前用户
├── Website/               官网静态站（下载 / 更新日志 / 隐私政策）
├── Linux/                 Qt 6 版（见 03）
├── Harmony/               ArkTS 版
├── Docs/                  设计、技术、更新记录、上架、合规 —— 见 08 索引
└── Scripts/               发布、打包、部署、PDF 转页图
```

Linux 版是**独立实现**，不复用 C# 代码：这边对应的是 `Services/I*.cs` 那六个
接口（`ISettingsService` / `IScreenTimeService` / `IAppCatalogService` /
`IAppLauncherService` / `IKioskService` / `IStoryService`），一个接口对应
`Linux/src/core/` 下一个 C++ 类。鸿蒙端也是同样的对应关系，只是语言是 ArkTS。

## 4. 三端「锁」的能力对照

| 手段 | Windows | Linux | Android |
| --- | --- | --- | --- |
| 开机自启 | HKCU `Run` → `--kiosk-guard` | XDG autostart / systemd `--user` | `BOOT_COMPLETED` + 前台服务 |
| 被杀后自愈 | 守护进程重启（连续 5 次快挂才放弃） | systemd `Restart=always` + 守护循环 | `START_STICKY` + 心跳闹钟 + 无障碍互拉 |
| 屏蔽系统快捷键 | 低级键盘钩子 | X11 `XGrabKey`；Wayland 靠会话裁剪 | 无障碍拦截 |
| 任务管理器 | 钩子 + `DisableTaskMgr` 策略（可逆备份） | 会话里压根没有 | — |
| 兜底 | 抢回前台 | 专用会话 | 自动回前台 + 设备管理员防卸载 |

`Ctrl+Alt+Del` 三端都拦不住 —— 这是系统安全序列，也是设计上**故意留的出口**。

完整方案与验收步骤：`Docs/开机自启与快捷键拦截.md`。

## 5. 服务端在哪

| 服务 | 位置 | 作用 |
| --- | --- | --- |
| 故事 / 学习 / 联机接口 | `Linux/server/kidssafe_story_server.py` | Python 3 零依赖，story / learn / game 三组接口 + 家长后台网页 |
| 账号与配对码 | 同上（1.3 起） | 一个服务器可以放多个家庭，配置按账号隔离 |
| 官网 / 反馈 / 发布信息 | `Website/` + 线上 `kids.siguangblog.cc` | 下载页、更新日志、反馈统计、家长后台 |

联机小游戏只做「4 位房间号熟人房」：服务端存的是**走法序列**而不是棋盘快照，
双方从开局重放必然一致，所以不需要 WebSocket，1.5 秒短轮询就够。

细节：`Docs/账号体系.md`、`Docs/实时下发通道.md`、`Linux/server/README.md`。

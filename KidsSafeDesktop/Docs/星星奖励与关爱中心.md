# 星星奖励 · 学习激励 · 关爱中心

> 本文对应 v1.16 的三块新能力：全应用统一的星星账本、所有小游戏的结算奖励页、
> 所有学习页的激励页，以及留守儿童关爱（心情日记 / 心理小课堂 / 呼吸放松 / 想对爸妈说）。
> 写这份文档的目的不只是备忘：上架审核如果问到「儿童激励设计」和「未成年人心理内容」，
> 这里可以直接作为说明材料。

## 一、为什么要做「星星」

儿童产品里的奖励很容易做坏，常见三种坏法：

1. **只有赢才有奖励** —— 输的孩子直接放弃，游戏变成筛选而不是练习；
2. **奖励可以无限刷** —— 孩子学会的是刷分，不是学习；
3. **公开排名** —— 变成攀比，落后的孩子受挫。

所以这里的规则是刻意「反直觉」的：

| 规则 | 取值 | 理由 |
|---|---|---|
| 输一局 | 至少 2 星 | 愿意坐下来试一次就该被看见 |
| 完成一局 | 至少 3 星 | 完成比正确更重要（对低龄尤其） |
| 满星（5 星） | 正确率 ≥ 95% | 有明确门槛，不是随手给 |
| 重复玩同一局 | 仍然记星星 | 练习本来就该被鼓励 |
| 同一个故事 | 每天只记一次 | 防刷，同时不惩罚重听 |
| 排行榜 | 仅本机、按游戏分开 | 不跨设备、不公开 |

星星**只存在本机**（`Preferences`），不上传、不联网、不进排行榜总分。
服务端没有星星相关接口——这是有意的：儿童数据能不出设备就不出。

## 二、代码结构

```
Models/RewardModels.cs      StarRecord / StarBadge / AwardResult / RewardOutcome
Services/StarCenter.cs      唯一账本：总数、今日、连续天数、勋章、记录（上限 80 条）
Pages/RewardResultPage      通用「本局结算」页（游戏）
Pages/EncouragePage         通用「学习激励」页（学习）
Pages/StarBoardPage         我的星星：总览 + 勋章墙 + 最近记录
Helpers/RewardWatcher.cs    监听游戏 ViewModel 的 Finished / GameOver，自动结算
Helpers/LearnCheckIn.cs     给学习页注入「🌟 学完了」浮动入口
```

### 1. 游戏结算怎么挂上去的

19 款游戏里，17 款是 MVVM，ViewModel 都有 `Finished` 或 `GameOver` 布尔属性并会发
`PropertyChanged`。`RewardWatcher.Attach(page, gameInfo)` 只做三件事：

1. 订阅 `BindingContext.PropertyChanged`；
2. 看到 `Finished/GameOver == true`，反射读 `ScoreText / ProgressText / ResultText`；
3. 用 `第 X / Y` 解析出正确率 → 换算星级 → 记账 → 压入 `RewardResultPage`。

所以**新增一款 MVVM 游戏不需要写任何结算代码**，只要 ViewModel 有 `Finished`。

两款例外：

- **围棋**：没有 ViewModel，页面在 `ShowResult()` 里显式调用
  `RewardWatcher.ShowForGameAsync(...)`，按目数差换算星级（输棋也给 2 星）。
- **涂鸦**：没有输赢，保存作品时给 3 星，每次进入只发一次。

「再来一局」通过反射调用 ViewModel 的 `Replay()`（数独是 `Start()`），
然后关闭结算页回到游戏，不会重建页面。

### 2. 学习激励怎么挂上去的

学习页没有天然的「结束」时刻，所以不猜：`LearnCheckIn.Attach(...)` 把一个
「🌟 学完了」的浮动按钮注入页面（包一层 Grid，不改 XAML），孩子点了才算打卡。

已接入的页面：

| 页面 | 学科 | 每次星星 |
|---|---|---|
| 古诗学习 / 口诀乐园 / 英语学习 / 口才练习 | ✅ | 2 |
| 身体百科 / 安全知识 / 科学实验室 / 语音训练 | ✅ | 2 |
| 眼保健操 | ✅ | 1 |
| 故事屋（在线）/ 星夜故事屋 | ✅ | 2 |
| 心理小课堂（正文页「我看完了」） | ✅ | 2 |
| 呼吸放松（完成 4 轮） | ✅ | 1 |

每个页面**每次进入只能打卡一次**，按钮点完变「✅ 已打卡」并淡出，避免连点刷星。

### 3. 勋章

17 枚，全部自动解锁，分四类：首次 / 连续天数（3·7·30）/ 累计星星（50·200·500·1000）/
行为（玩过 5·10·19 款游戏、学习 10·50 次、满星、家务 10 件、故事 5 个、心情 7 天）。

勋章进度用「3 / 7 天」这种形式展示，未解锁也有进度，不给孩子「一片空白」。

## 三、小小家务英雄

`Pages/ChoreHeroPage` + `Services/ChoreService`，对应设计稿 kids.html 的三个 Tab。

- **家庭积分是独立账本**，和星星分开：因为兑换要扣分，而星星只增不减。
  两套账混在一起会出现「兑换奖励把游戏星星扣掉」的怪事。
- 家长确认一件家务时，额外给星星中心记 2 颗（用于「家务小帮手」勋章），不动家庭积分。
- 家长模式**每次进入都要重新验证**（`ParentMode` 在构造时强制置 false），
  避免孩子上次看家长切过就一直停留在家长视角。
- 全勤 +10、连续 7 天 +20，与设计稿一致；`LastBonusDate` 防重复发放。

## 四、星夜故事屋（TTS）

`Models/StoryHouseData.cs` 内置 14 个故事，**完全离线**（留守家庭网络常不稳定）。

朗读为何按段：

1. 整篇交给系统 TTS 就不知道读到哪，无法高亮和进度；
2. 段间停顿可以做出「慢 / 正常 / 稍快」，因为 `SpeechOptions` 没有语速参数；
3. 停止能在段边界立刻生效，长故事不会停不下来。

`Tts.SpeakAsync(text, locale, CancellationToken)` 是本次新增的重载，
取消后立即退出循环；睡眠定时到点会 `Cancel` 并弹出「晚安」遮罩。

### 声音风格（v1.17 补）

一台设备通常只有一个中文音色，换发音人做不到（要接云端 TTS，与离线优先冲突）。
`Models/VoiceStyleData.cs` 给的是四个**音高 + 停顿倍率**预设：

| 风格 | 音高 | 停顿倍率 |
|---|---|---|
| 🌸 温柔姐姐 | 1.12 | ×1.25 |
| 🧓 慈祥爷爷 | 0.84 | ×1.45 |
| 🐣 活泼小伙伴 | 1.32 | ×0.82 |
| 📖 标准朗读 | 1.00 | ×1.00 |

实际停顿 = 节奏档位基础值 × 倍率，夹在 80–1800ms。界面上写明「调的是音高和停顿，
不是换配音演员」，避免家长以为点了没生效。

### 故事图片卡（v1.17 补）

播放页底部「📤 把故事做成图片卡」→ `Pages/StoryCardPage` 预览 → `View.CaptureAsync()`
截图 → 系统分享面板。

用 XAML 排版而不是 SkiaSharp 绘制，是为了「看到的卡片」和「导出的图片」完全一致。
代价是卡片必须先渲染（截图 API 只能截界面上的 View），所以做成预览页而不是后台静默生成。
另给「📋 复制文字」退路——有些聊天软件会把长图压花。

## 五、关爱中心（留守儿童心理健康）

### 内容原则

1. **不把「留守」写成缺陷**：孩子不是问题儿童，只是家里的大人暂时不在身边；
2. 每节课都给「现在就能做的一个动作」，不讲大道理；
3. 明确澄清最常见的自我归因——「爸爸妈妈外出不是因为你不好」；
4. 出现自伤念头必须指向真实可用的求助渠道，不做「想开点」这种无效安慰；
5. 家长篇不指责家长，给的是「15 分钟怎么打电话」这类可执行动作。

### 功能

| 模块 | 说明 |
|---|---|
| 今日心情 | 8 种表情，点一下即记录，理由可不写；每天可改 |
| 心情日记 | 最近 14 天趋势、记录天数、连续天数、最常见心情 + 一句观察 |
| 心理小课堂 | 10 节给孩子、10 节给家长；每节可朗读，读完进激励页（家长篇 6 节整理自公开媒体文章，见 `Docs/关爱中心-家长课素材.md`） |
| 呼吸放松 | 4-7-8 呼吸，圆圈缩放 + 秒数倒计时，4 轮后可领 1 星 |
| 想对爸妈说 | 写一句话存本机，可用 TTS 读出来；给 6 个开头降低门槛 |
| 求助渠道 | 12355 / 12338 / 110 / 120 / 学校心理老师 / 村儿童主任，可一键拨号 |

### 隐私边界（重要）

- 心情记录、留言**只写本机 `Preferences`**，无网络请求、无云端同步、无账号绑定；
- 家长面板**不展示**心情内容明细，只展示「最近记录天数」；
- 不采集定位、通讯录、设备标识；
- 页面底部明示「只保存在这台设备上，不会上传」。

### 内容分级

- 面向孩子的内容涉及**身体界限与自我保护**（隐私部位的正确名称、可以拒绝、要告诉大人），按学龄期能理解的程度写，**不涉及性行为细节、暴力细节与自杀方法描述**；
- 性教育、防猥亵、网络社交的完整分年龄讲法写在家长侧（成长指南），孩子侧只保留可执行的短句；
- 「哪些信号需要专业帮助」只写给家长看，且只描述**信号与行动**，不描述方法；
- 求助渠道为公开的公益热线，未编造号码；各地另有未成年人保护热线，可通过 12345 查询。

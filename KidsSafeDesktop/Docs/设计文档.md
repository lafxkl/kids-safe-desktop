## 1. 项目概述

「儿童安全桌面」是一个面向 3–12 岁儿童的 **双端（Android + Windows PC）桌面环境**，由 .NET MAUI 单代码库构建。它在孩子面前呈现一个受控、童趣、可玩的环境；在家长面前提供独立的「家长后台」与可选的「家长端服务器」做远程管理。

本次迭代在既有功能（小游戏、家长后台、主题、喜马拉雅入口）之上，新增多块能力：

1. **天气显示 + 自动网络定位**：主页自动展示当地实况天气。
2. **家长端服务器（远程管理）**：家长可在电脑网页上统一管理多台设备的配置，儿童端一键同步。
3. **喜马拉雅入口 → 已升级为离线音频中心**：早期版本用网页控件收听第三方儿童内容，现已改为随包发布的离线内容（详见第 24 条）。
4. **账号体系 + 离线模式**：首次运行自动创建本地账号，默认离线可用；可连接家长端服务器切换为在线。
5. **媒体中心（听一听）**：统一的音频中心。早期聚合贝瓦儿歌、喜马拉雅儿童、宝宝巴士等第三方提供方，
   现已全部改为随包发布的离线内容（详见第 24 条）。
6. **天气升级为逐小时预报 + 预警**：主页展示未来逐小时温度，并依据预报数据自动推导高温/降雨/大风等预警。
7. **安全知识板块 + 安全小问答游戏**：新增「🛡️ 安全知识」主页入口，按主题浏览安全小贴士（交通/防火/防骗/防溺水等）；并新增「安全小问答」益智游戏，用选择题闯关，学会保护自己。
8. **涂鸦 + 大鱼吃小鱼**：新增「🎨 快乐涂鸦」（手指绘画，含调色板/笔刷/橡皮/撤销/保存）与「🐟 大鱼吃小鱼」（实时躲避与吞噬，吃小鱼长大、被大鲨鱼吃掉结束，成绩计入排行榜）。
9. **算术乐园 + 数独小游戏**：新增「🔢 算术乐园」（按难度生成加减乘除算式，选择题闯关，结束计入排行榜）与「🧠 数独」（4×4 儿童版，数字键盘填数，自动校验，完成计入排行榜）。
10. **口诀乐园（乘法 / 加减法 / 除法口诀）**：首页新增「📚 口诀乐园」入口，含九九乘法表、凑十歌与减法小窍门、除法口诀与除法表，以表格/儿歌形式呈现，离线内置。
11. **版本显示**：家长后台、账号页与首页底部均展示应用版本号（取自 csproj 的 `ApplicationDisplayVersion`）。
12. **开心识字 + 拼音识字**：新增「😊 开心识字」（看汉字，从 emoji 图画中选出对应的那一张，强化「字→图」认读）与「🔤 拼音识字」（看汉字配图，从若干带声调拼音中选出正确读音）。两游戏共用现有难度与排行榜体系。
13. **学习天地（一年级～初三口算练习与批改）**：首页新增「📖 学习天地」入口，进入后按年级（一至六年级 + 初一/初二/初三）选择，系统按课标难度出题（一到四年级现场随机生成，五年级起从 SQLite 题库取题），儿童输入答案，即时批改并生成成绩报告（正确率 / 得分 / 用时 / 错题回顾）。**题目带中文语音朗读**（TTS 实时报题，如「二十三 加 五 等于 多少」），并提供「🔊 读题」按钮重听；五～九年级题目来自 SQLite 题库，答案支持小数与负数（输入框右侧「±」）。
14. **英语学习（一年级～初三单词认读与练习）**：首页新增「🔤 英语学习」入口，进入后按年级（一至六年级 + 初一/初二/初三）选择，提供两大模式——**学习模式**（按主题分类浏览单词卡：emoji 配图 + 英文单词 + 音标，点「看意思」显中文、点「听发音」用英文 TTS 朗读）与**练习模式**（看英文选中文释义的选择题，即时批改、成绩报告与错题回顾）。词库覆盖动物 / 水果 / 颜色 / 数字 / 家人 / 食物 / 衣物 / 学校 / 身体 / 天气 / 动作 / 形容词 / 职业 / 家居 / 学科 / 描述等主题。
15. **小游戏新增：百科问答 / 打地鼠 / 打字游戏 / 欢乐打气球**：「小游戏乐园」新增四类趣味游戏——「📚 百科问答」（知识选择题闯关，自动朗读题目）、「🔨 打地鼠」（9 洞随机冒头点击得分）、「⌨️ 打字游戏」（跟着读音把英文单词打出来，TTS 朗读目标词）、「🎈 欢乐打气球」（气球上升点击爆破得分）。四类均限时计分并进入排行榜。
16. **眼保健操**：首页新增「👀 眼保健操」磁贴，分节引导（闭眼放松 / 按揉睛明穴 / 转动眼球 / 远眺），每节带倒计时与中文语音提示，培养护眼好习惯。
17. **身体百科**：首页新增「🧍 身体百科」磁贴，按「头部 / 四肢 / 身体内部」分类浏览身体部位（大脑、眼睛、心脏、骨骼等），含说明与趣味知识，可语音朗读部位名称。
18. **TTS 实时语音全面接入**：统一封装 `Helpers/Tts`（可指定语言），已接入「学习天地」口算报题、百科问答、英语单词、识字 / 拼音游戏朗读、眼保健操与安全问答引导，让小朋友「听得到、读得出」。
19. **操作帮助中心（含 TTS 配置指引）**：首页新增「❓ 操作帮助」磁贴，分三大分类共 17 条说明——**操作指南**（首页按钮、小游戏乐园、学习天地、英语学习、眼保健操、身体百科、家长后台、时长锁屏）、**语音配置**（语音自检流程、Windows 安装语音包、Android 安装语音包、有语音包仍无声的排查、英文读不出来的处理）、**常见问题**（朗读无声、天气不显示、儿歌播放无声、忘记家长验证、退出儿童模式、成绩未入榜）。页面顶部提供**语音自检卡片**：状态灯 + 诊断信息 + 「🔊 试听中文 / 🔤 试听英文 / 🔄 重新检测 / ⚙️ 系统语音设置」四个按钮，其中「系统语音设置」可一键跳转 Windows「设置 → 语音」或 Android「文字转语音(TTS)输出」。启动探测发现无语音包时，弹窗提供「打开帮助」按钮直达配置指引。
20. **护眼模式（全局蓝光过滤）**：家长后台新增「👁️ 护眼模式」设置区，支持三种用法——**常开**、**强度调节**（滑块，柔和 / 标准 / 强力，实时显示滤镜百分比）、**定时自动生效**（设定起止小时，支持跨零点，如 19:00–07:00）。开启后在**全屏（含所有原生页面与网页游戏）之上**叠加暖色滤镜，降低蓝光刺激；遮罩不拦截任何触摸操作，游戏与交互完全不受影响。护眼生效时**首页顶部显示「👁️ 护眼」徽章**，家长后台状态行显示「当前生效中 ✅ / 当前未生效」。设置保存后立即应用，无需重启。
21. **游戏乐园（内置 15 款网页游戏）**：首页新增「🕹️ 游戏乐园」磁贴，将完整网页游戏合集**原样内置**到桌面端，**无需联网、零外部依赖**。包含 🚀 雷霆战机、🎯 欢乐五子棋（双人 & 人机 AI）、🐍 贪吃蛇大冒险、💎 萌趣宝石消消乐、🦁 森林斗兽棋、♟️ 中国象棋、🐧 冰雪打企鹅、🔟 萌趣凑十消消乐、🛩️ 算术小飞行员、📜 点字成诗大闯关、🧩 汉字合体消消乐、🎈 听音识字打气球、🖼️ 象形字翻翻看、🚗 小汽车大冒险、💎 光线宝石。页面顶部提供「返回 / 大厅 / 刷新」工具栏，外链自动交由系统浏览器打开，安卓端已开启 JS 与音频自动播放支持。
22. **启动动画（标语：守护儿童网络安全）**：应用启动时先进入启动页，由 `SplashDrawable`（`GraphicsView` + `IDrawable`）逐帧绘制守护主题动画——糖果渐变背景与漂浮柔光泡泡、弹性入场的**守护之盾**（内含守护者笑脸）、旋转的虚线光环、向外扩散的波纹、沿椭圆轨道环绕的星点，随后依次浮现应用名「儿童安全桌面」、**标语「守护儿童网络安全」**（逐字揭幕）与英文名。动画最短播放 2.6 秒，期间**并行完成初始化**（读取设置 → 准备护眼滤镜 → 检查账号 → 启动时长守护 → 进入儿童模式），进度条反映真实加载进度；就绪后淡出并切换到首页，避免白屏、黑屏与卡顿感。
23. **任务栏恢复与异常退出兜底（Windows）**：修复「程序异常结束后系统任务栏消失、必须手动重启资源管理器」的问题。原实现在进入儿童模式时隐藏任务栏，但仅在「家长后台正常退出」一条路径上恢复。现改为**四层兜底**——① 窗口激活跟踪（只有本应用在前台时才隐藏，失焦/关闭立即恢复）、② `ProcessExit` 钩子、③ 未处理异常钩子（UI 线程 / 后台线程 / 未观察 Task）、④ **启动自检标记文件**（发现上次残留标记即自动恢复）。另在帮助页提供「🖥️ 恢复任务栏」一键自救按钮。
24. **听一听升级为离线音频中心（修复「点了跳官网」）**：原「听一听」把第三方儿童站塞进网页控件，所有分类都指向 **官网首页**（贝瓦、宝宝巴士）或 **搜索页**（喜马拉雅），需要二次操作才能听，且站内混有登录墙、VIP 弹窗和成人向推荐内容。现**彻底移除第三方网页跳转**，改为随包发布的离线内容 + 各平台原生播放器（Windows 用 WinRT 播放器、Android 用 MediaPlayer），首页卡片标注「📦 离线可用」。包含六个分类：**🎵 儿歌音乐盒**（8 首公有领域经典童谣，自行合成的音乐盒音色）、**🌙 安睡摇篮**（雨声 / 海浪 / 白噪音，循环播放）、**📚 睡前故事**（6 篇原创小故事）、**🏮 国学启蒙**（唐诗与三字经）、**🔤 英语启蒙**（英文原声单词句）、**🔬 科普知识**（十万个为什么）。播放页支持播放/暂停、上一首/下一首、进度拖动，儿歌播完自动接下一首；朗读类内容由系统语音逐句朗读并**高亮当前句**。因彻底去除外部依赖，断网也能听。
25. 配套 **设计文档 + 技术文档 + 软著申请物料**（`Docs/软著申请材料/`：材料清单与流程、申请表草稿、用户操作手册、源程序前后各 30 页、权利保证书、开发与运行环境说明）。

## 2. 目标用户与场景

| 角色 | 诉求 | 对应能力 |
|------|------|----------|
| 儿童 | 好看、好点、能玩、能听故事 | 童趣主题、小游戏、喜马拉雅播放、天气 |
| 家长（本地） | 控制可用应用/时长/游戏 | 家长后台（本地） |
| 家长（远程） | 不在设备旁也能改配置 | 家长端服务器 + 同步 |
| 运维/研发 | 可部署、可排查 | 服务端 REST + 静态仪表盘 |

## 3. 总体架构

```
┌─────────────────────────────┐        HTTP/JSON        ┌────────────────────────────┐
│   儿童安全桌面（MAUI 客户端） │  ───────────────────▶  │   家长端服务器（ASP.NET）   │
│   Android / Windows          │   GET/PUT /api/settings │   Program.cs (Minimal API)  │
│                              │   POST /api/auth/login  │   ProfileStore (JSON 文件)  │
│  • 儿童主页 / 小游戏 / 主题   │ ◀───────────────────   │   wwwroot/index.html 仪表盘 │
│  • 家长后台（本地）           │                         └────────────────────────────┘
│  • 天气/定位、喜马拉雅播放     │
└─────────────────────────────┘
```

- **客户端**：单一 MAUI 项目，双 `TargetFramework`（`net10.0-android`、`net10.0-windows10.0.19041.0`），通过 `#if ANDROID / WINDOWS` 注入平台实现。
- **服务端**：独立的 ASP.NET Core 项目（`KidsSafeServer`），与客户端解耦，可单独部署在任意能跑 .NET 10 的机器/容器内。

## 4. 功能模块

### 4.1 儿童主页
- 头像（点按改名）、昵称、剩余时间、换皮肤按钮、**账号模式徽章**（离线 🟢 / 在线 ☁️，点按进入账号页）。
- **天气卡片**：联网定位后显示 emoji + 温度 + 城市；升级为「逐小时预报 + 预警」展示（见 4.6）。断网/超时优雅隐藏。

### 4.2 小游戏（18 个）
看图识字、数一数、配对、找颜色、听音选物、连连看、走迷宫、安全小问答、快乐涂鸦 🎨、大鱼吃小鱼 🐟、**算术乐园 🔢**、**数独 🧠**、**开心识字 😊**、**拼音识字 🔤**。难度在大厅统一选择，成绩进入排行榜（涂鸦为创意类，不计入排行）。

### 4.3 家长后台（本地）
密码、每日时长、允许应用、小游戏开关、允许网站、排行榜清理、**账号与云端同步入口**、**「家长端服务器」分区**。

### 4.4 主题系统
暖阳 / 蓝天 / 彩虹 三套童趣主题（背景图 + 渐变 + 强调色），`🎨` 一键切换并持久化。

### 4.5 媒体中心（听一听 · 离线音频）
- 首页磁贴「🎵 听一听」进入**媒体中心**：按内容分类分区展示，**全部为 App 自带内容，不加载任何外部网页**。
- 六个分区：🎵 儿歌音乐盒（8 首公有领域经典童谣，音乐盒音色合成）、🌙 安睡摇篮（雨声/海浪/白噪音，循环）、
  📚 睡前故事（6 篇原创故事）、🏮 国学启蒙（唐诗与三字经）、🔤 英语启蒙（英文原声）、🔬 科普知识（十万个为什么）。
- 点任意卡片 → **播放页**：音乐与环境音由自建的原生播放服务播放随包音频文件；朗读类由系统语音逐句朗读并高亮当前句。
- 统一传输控制（上一首 / 播放暂停 / 下一首），儿歌播完自动接下一首；离开页面自动停止播放。
- 内容在 `KidsAudioData` 中集中配置，儿歌/环境音由 `Docs/tools/generate_kids_audio.py` 生成，便于扩充。

### 4.6 天气 + 自动定位（逐小时 + 预警）
- 定位：`auto` 时用 `ipwho.is` 做 IP 定位；指定城市时用 Open-Meteo 地理编码按城市名解析。
- 天气：Open-Meteo 当前实况 + **逐小时预报**（未来最多 12 小时，含温度、emoji、降水概率）。
- **预警推导**：Open-Meteo 免费接口不含官方预警，故依据逐小时数据本地推导（高温/低温/降雨/大风/雾/雷暴），分「预警/注意」两档，无网络官方源也能用。
- 城市可由家长后台或服务器统一管理（`WeatherCity`）。

### 4.7 家长端服务器（远程管理）
- 家长在网页仪表盘配置：时长、昵称、天气城市、游戏开关、主题、喜马拉雅默认分类、允许应用白名单。
- 儿童端「登录 → 同步」后把服务器配置合并到本地 `ChildSettings`。
- 默认鉴权密码 `1234`（服务端 `appsettings.json` 的 `AdminPin` 可改）。

### 4.8 账号体系 + 离线模式
- **本地优先、离线可用**：首次运行 `AccountService` 自动创建本地账号（昵称 + 头像），默认即为**离线模式**——所有设置保存在本机，无需账号也能完整使用。
- **在线模式**：在「账号页」或家长后台填入家长端服务器地址并登录，即切换为**在线模式**，配置由服务器统一下发/同步；可随时「断开连接」转回离线。
- 账号页（`AccountPage`）支持修改昵称头像、查看模式、连接/断开服务器；主页右上角徽章实时显示当前离线/在线状态。

### 4.9 安全知识板块 + 安全小问答
- **主页入口**：首页新增「🛡️ 安全知识」磁贴（与「小游戏乐园」「听一听」并列），进入安全知识板块。

`App.OnStart` → 加载设置 → 主页 `OnAppearing`：刷新应用磁贴（带真实图标）、启动时钟、加载天气。

### 5.3 远程同步
```
家长后台填写服务器地址 → 输入密码「登录」(POST /api/auth/login)
                                        ↓ 保存令牌
                                  「立即同步」(GET /api/settings?token=)
                                        ↓ 合并到 ChildSettings
                                  本地 UI 刷新 + 存档 + 应用主题
```

## 6. 安全设计

- **本地 PIN**：SHA256 加盐哈希，存于 `SecureStorage`（回退 `Preferences`）。
- **家长门禁**：儿童模式禁止返回键，家长入口需独立鉴权。
- **应用白名单**：仅展示/启动家长允许的应用或网址。
- **服务器鉴权**：共享令牌模型（`kids-admin-token`）。适合家庭局域网/受信任环境；公网部署需前置 HTTPS 反向代理与更强鉴权（见技术文档「已知限制」）。
- **内容安全**：「听一听」不加载任何外部网页，全部内容为内置离线资源，避免广告、登录墙与不可控推荐。

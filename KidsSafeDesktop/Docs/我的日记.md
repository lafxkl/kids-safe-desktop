> 入口：首页图标「🔐 我的日记」、关爱中心「我的日记」卡片
> 最后更新：2026-11-05

## 一、它和「心情日记」不是一回事

| | 心情日记（已有） | 我的日记（本功能） |
|---|---|---|
| 入口 | 关爱中心 → 看趋势 | 首页 / 关爱中心 |
| 形式 | 每天一条心情 + 一句话（≤40 字） | 自由书写，单篇 ≤20000 字，可起标题、选心情 |
| 设防 | 无 | **孩子自己设的 4 位数字密码** |
| 家长能看到吗 | 天数与心情分布（不含留言内容） | **完全看不到内容**；只有孩子忘记密码、家长主动重置后才可读 |
| 定位 | 让情绪被看见 | 让孩子有一个可以不被看见的地方 |

两者并存是刻意的：不是所有情绪都适合「被统计」。心情日记解决「说不出口」，我的日记解决「不想给任何人看」。

## 二、密码怎么设计的

### 孩子自己设，我们不知道

首次进入时自己设一个 **4 位数字**，输两次确认。选数字而不是字符，是因为孩子记得住键盘位置，也绕开了中文输入法的坑。

存储的不是密码，是 **PBKDF2-HMAC-SHA256 派生值**：

```
salt = 16 字节随机数（每台设备、每次重设都不同）
hash = PBKDF2(pin, salt, 100000 次, SHA256, 32 字节)
```

两个细节：

- 用 `CryptographicOperations.FixedTimeEquals` 比较，不做逐字节短路比较（防时序侧信道，虽然本地场景意义有限，但不该写坏习惯）。
- 4 位数字本身只有 1 万种可能，所以真正起作用的是「10 万次迭代 + 输错冷却」的组合：离线爆破每次要算 10 万次哈希，在线试错 5 次就被挡住 60 秒。

### 输错有代价，但不拿内容当人质

| 累计输错 | 冷却 |
|---|---|
| 5 次 | 60 秒 |
| 8 次 | 180 秒 |
| 12 次起 | 300 秒 |

冷却时间**落盘**（`LockedUntilTicks`），杀掉应用重开也绕不过去。任何情况下都不删日记——惩罚不该落在孩子写下的东西上。

输到第 2 次会把孩子自己留的提示语显示出来（设置密码时可选填）。孩子忘了密码，先靠自己留的线索，而不是立刻去叫家长。

### 忘记密码：只能家长重置，并且要讲清楚代价

「忘记密码」按钮 → 提示需要家长密码 → 输入家长密码（`ISettingsService.VerifyPin`）→ 选重置方式：

1. **只重置密码（内容保留）**：清空日记密码，`N 篇内容都还在`，孩子重新设一个。**此时家长可以打开日记看到内容。**
2. **重置并清空全部日记**：二次确认后删除文件，谁都看不到。

这句话直接写在**设密码那个页面**上，不藏在隐私政策里：

> 如果忘了密码，只能请家长用家长密码帮你重置——日记内容会保留，但家长也能看到。
> 所以不想让人看到的东西，别写在这里。

为什么不做得更「安全」（比如永不可重置）：那意味着孩子忘一次密码就永久失去全部日记，对 6–12 岁是灾难性的体验。为什么不做得更「方便」（比如密保问题）：答案往往是「我妈妈的名字」，比密码还好猜，是自欺欺人。**诚实地告诉孩子这条边界，比给他一个假承诺更有价值。**

## 三、数据怎么存的

```
<AppDataDirectory>/diary_v1.json
```

```json
[{ "Id":"…", "Date":"2026-11-05", "Time":"20:15",
   "Title":"", "Body":"…", "MoodId":"happy",
   "UpdatedAt":"2026-11-05 20:31:02" }]
```

- 写入用「临时文件 + `File.Move(overwrite)`」，写到一半断电不会把整本日记写坏。
- 读失败（文件损坏）时当作空本子，**原文件不覆盖、不删除**——还有救。
- 上限 2000 篇 / 单篇 20000 字。超了丢最旧的，而不是拒绝写入：不能让孩子正写着突然存不进去。
- **没有做文件加密**，这是有意的：能读到这个文件的人（root、备份、调试连接）同样能读到代码里的密钥，加密只是自我安慰。真正的防线是密码页 + 系统沙箱。代价写进了隐私政策。

## 四、几个体验上的决定

| 场景 | 处理 | 为什么 |
|---|---|---|
| 写一半来电 / 锁屏 | `OnDisappearing` 自动静默保存 | 孩子写东西比成人更容易被打断，丢字会直接摧毁信任 |
| 离开页面 | 立刻重新上锁 | 手机递给同学的那一刻，日记不该还开着 |
| 标题留空 | 显式显示「无题」 | 不逼孩子起标题，但列表里不能是空白 |
| 不知道写什么 | 12 条引子，「换一句」可轮换 | 同一天固定同一句，孩子会觉得这句是今天专属的 |
| 字数统计 | 用 `Rune` 枚举，emoji 与标点不计 | 按 `char` 数会把一个 😄 算成 2 个字，孩子写满表情看到「20 字」很出戏 |
| 内容为空时保存 | 新篇丢弃、旧篇不改 | 不清空孩子之前写的东西 |
| 给不给星星 | **不给** | 星星会出现在星星榜与家长面板，等于告诉家长「孩子今天写了日记」，与「不进入家长面板」自相矛盾 |

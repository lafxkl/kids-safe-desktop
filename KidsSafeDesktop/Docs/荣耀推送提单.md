荣耀推送 10202 工单材料（可直接复制到提单页）
====================================================

【问题标题】
Push Kit getPushToken 持续返回 10202，包名与 SHA256 指纹均与平台登记一致

【应用信息】
应用名称：儿童安全桌面
APP ID：104600830
包名：com.companyname.kidssafedesktop
推送 SDK：push-10.0.39.302.aar / pushcommon-10.0.39.302.aar（控制台下载）

【设备信息】
机型：荣耀设备（checkSupportHonorPush 返回 true）
系统：Android 16（Baklava）
推送服务：已安装，可正常绑定

【问题现象】
调用 HonorPushClient.getInstance().init(context, false) 后
getPushToken() 回调 onFailure(10202, "parameter error")，始终无法获取 token。
设备网络正常，应用已用正式签名证书打包安装。

【已排查（均为实测，非推测）】
1. 包名
   - 平台登记：com.companyname.kidssafedesktop
   - 安装包实际：com.companyname.kidssafedesktop
   - 诊断页读取：com.companyname.kidssafedesktop
   三方逐字一致。

2. 证书指纹（SHA256）
   - 平台登记：E0:52:70:93:2C:2F:6F:ED:2A:5E:CF:33:89:BC:45:B3:B0:D2:06:CA:AC:DA:11:C8:A9:39:E1:20:AD:55:CD:35
   - keytool -printcert -jarfile 输出：同上
   - apksigner verify --print-certs：e05270932c2f6fed2a5ecf3389bc45b3b0d206caacda11c8a939e120ad55cd35
   - 应用内 PackageManager 读取：同上
   三方一致；APK 同时具备 v1/v2/v3 签名，单一签名者，无密钥轮换。

3. App ID
   - AndroidManifest 中 meta-data com.hihonor.push.app_id = 104600830
   - assets/mcs-services.json 中 app_id = 104600830、developer_id = 110000279716
   - 反编译 SDK 确认 com.hihonor.push.sdk.x.a(Context) 组装 RequestHeader 时
     用 Bundle.get + String.valueOf 读取该 meta-data，
     即使 aapt2 把值编译成 int 也能正确得到字符串 "104600830"，
     因此不存在「类型不对导致 appId 为空」的可能。

4. 清单与资源
   - <queries> 已声明 action com.hihonor.push.action.MESSAGING_EVENT（targetSdk>=30 包可见性）
   - 自定义 KidsHonorMessageService 已注册，exported=false，intent-filter 同上
   - assets/mcs-services.json 已打包进 APK 根 assets 目录

【结论】
客户端上报的三个校验字段（appId / packageName / certificateFingerprint）
与平台登记值完全相同，但服务端仍返回 10202。
平台侧显示「已获得权限 0 / 驳回权限 0」，即推送服务权限既未通过也未驳回，
应用信息尚未在推送服务端生效。10202 的文案虽写「包名或指纹不一致」，
实际是服务端查不到该 APPID 的生效绑定记录。

请协助确认：
1. 该应用的推送服务权限当前处于什么状态（待审核 / 审核中 / 未提交）；
2. 该账号为个人开发者账号，是否具备开通荣耀推送服务的资质；
3. 若需补齐资料，请明确需要哪些材料。
